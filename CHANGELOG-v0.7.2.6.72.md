# v0.7.2.6.72 — Searching button label while checking updates

- Clicking **Check for Updates** no longer shows the orange "Scanning Windows updates and drivers…" status text beside the button.
- While the scan runs, the button label itself switches to **Searching....** (English) or **Søker....** (Norwegian); idle label stays **Check for Updates** / **Søk etter oppdateringer**.
- Label resets on success, failure, and other end paths.
