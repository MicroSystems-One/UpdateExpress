# Update Express v0.7.2.6.61

- A PC that has been running for 7 days or more shows a separate restart suggestion. It does not blink, and it stays hidden while Windows reports that a restart is required.
- Uptime (days:hours:minutes:seconds) is shown after the device name. The tooltip and copy include the last reboot time.
- Windows Update Control and Results can be collapsed. Collapsing Results gives that space back.
- Installation Manager shows each selected update while it downloads, then while it installs.
- A failed history row is hidden when the same update already succeeded. Hide removes it from this overview only. Install again runs when Windows still offers that update.
- The Install button returns to its label after history finishes loading.
