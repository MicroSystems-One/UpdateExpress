# Update Express v0.7.2.6.54

- Keep Windows Update history in Update Express when a fix resets the cache, and mark a row Fixed when a later success exists or the update that was fixed is no longer offered.
- Show Defender signature history (KB2267602) as Moderate (K3).
- Allow manual firmware installation after confirmation. Firmware stays unselected and is not installed automatically.
- History PDF shows `Error: none` when there is no error code, and a bold closing status with the report time.
